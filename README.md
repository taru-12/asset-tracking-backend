# Internal Asset Tracking Management System - Backend

## Features
- User Authentication (JWT)
- Role Based Access (Admin)
- Add Asset
- Assign Asset
- Return Asset
- MongoDB Atlas Database

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

## API Endpoints
POST /users/login
POST /assets
GET /assets
PUT /assets/:id/assign
PUT /assets/:id/return
